# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Install

```bash
cd docs
npm install
cd server
npm install
```

### Step 2: Start

```bash
# Terminal 1: Backend
cd docs/server
npm start

# Terminal 2: Frontend  
cd docs
npm run dev
```

### Step 3: Use

1. Open `http://localhost:8080`
2. Go to Settings → Enter Gemini API key
3. Go to AI Chat → Start planning your project!

---

## 📋 What Happens Next?

1. **Chat with AI** about your project idea
2. **AI creates BLUEPRINT.md** automatically
3. **Open Cursor IDE** → It reads the blueprint
4. **Start coding** → Cursor updates PROGRESS.md automatically
5. **Track progress** in the web viewer

---

## 🎯 That's It!

The system handles everything automatically. Just chat, code, and track!

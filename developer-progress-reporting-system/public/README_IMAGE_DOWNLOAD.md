# How to Add the Animated Sunny Background Image

## Step 1: Download from Pinterest

1. Open the Pinterest link in your browser: https://pin.it/3QHAx20Uf
2. Click on the image to view it in full size
3. Right-click on the image
4. Select "Save image as..." or "Download image"
5. Save it with the name: `animated-sunny-background.jpg`

## Step 2: Place the Image

Move the downloaded image to this folder:
`mixamo-clone-v2/docs/public/animated-sunny-background.jpg`

## Step 3: Verify

Once the image is in place, the background will automatically appear in the greeting section with:
- Faded edges that blend seamlessly
- Proper opacity and overlay effects
- Text remains visible and readable

The CSS is already configured and ready!
